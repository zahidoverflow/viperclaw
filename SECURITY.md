# Security Policy & Responsible Use

## Authorized Testing Only
ViperClaw is designed exclusively for authorized penetration testing, bug bounty programs within defined scope rules, CTF competitions, and white-box code auditing of software you own or have permission to test.

## Reporting a Vulnerability in ViperClaw
If you discover a security issue in ViperClaw itself (for example, path traversal or command injection in an analyzer or MCP handler), please open a GitHub Security Advisory on [`zahidoverflow/viperclaw`](https://github.com/zahidoverflow/viperclaw/security/advisories) rather than filing a public issue with exploit details.
