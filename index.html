🚀 Quickstart

1. Clone, Install Package & Load 12 Agent Skills 
git clone https://github.com/zahidoverflow/viperclaw.git
cd viperclaw
pip install -e .

# Install all 12 skills into Antigravity, Claude Code, Codex & Cursor
viperclaw skills install --target all
2. Connect Phase-Gated MCP Server (mcp_config.json / .mcp.json) 
{
  "mcpServers": {
    "viperclaw": {
      "command": "viperclaw",
      "args": ["mcp"]
    }
  }
}

💻 Standalone CLI Usage (viperclaw / vclaw)

CLI Workflows (Live DAST, White-Box SAST, JS Recon, HAR & Graph) 
# 1. Stateful live web scan & wire-verified exploit suite
viperclaw scan http://127.0.0.1:4280 --db .viperclaw/graph.db --report-md bounty_report.md --report-sarif findings.sarif

# 2. Multi-language source-to-sink taint SAST (Python, TS/JS, Go, PHP)
viperclaw taint ./target-repo --db .viperclaw/graph.db --output taint_flows.json

# 3. Reconstruct hidden Webpack / Vite / Next.js lazy chunks & API leads
viperclaw harvest-js ./bundles --base-url https://app.target.tld/ --db .viperclaw/graph.db --output js_recon.json

# 4. Fingerprint backend stacks from Caido / Burp HAR traffic & view top leads
viperclaw fingerprint ./traffic.har --domain target.tld --output tech_stack.json
viperclaw graph --db .viperclaw/graph.db --top-leads 10 --mermaid
